# Technology Stack

> RobelKaroseri Management System

## Runtime & Frontend
- **Bundler:** Vite
- **Library:** React (Single Page Application / SPA)
- **Bahasa:** TypeScript

## Backend & Database
- **BaaS Provider:** Supabase
- **Database Utama:** PostgreSQL (Relasional murni dengan kapabilitas JSONB)
- **Supabase Features:** Supabase Auth, Storage, dan Realtime subscriptions

## Styling & UI Components
- **Framework CSS:** Tailwind CSS
- **Ikonografi:** Lucide React
- **Tema Visual:** Industrial Theme (terinspirasi dan diadaptasi dari struktur UI referensi Google Stitch MCP, khusus untuk login card, layout, dan keypad tablet).

## Validasi Skema
- **Library:** Zod (Validasi form dan tipe data end-to-end)
