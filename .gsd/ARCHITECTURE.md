## Data Flow

1. User accesses application through `main.tsx` -> `App.tsx`.
2. `AuthContext` checks session with Supabase.
3. If logged out, user is routed to `LoginPage`.
4. Upon login, Supabase sets session, `AuthContext` fetches `roles` from the `profiles` table.
5. User is routed to the appropriate dashboard via `ProtectedRoute`.
