## Overview

The KAROSERI application is a web-based auto body shop management system. It provides role-based dashboards and operational workflows for different staff members (Owner/Admin, Service Advisor, Warehouse Officer, Mandor, and Cashier), integrating with Supabase for backend database and authentication.

## Data Flow

1. User authenticates via `LoginPage.tsx` interfacing with Supabase Auth.
2. `AuthContext` retrieves the session and the user's role profile.
3. `App.tsx` routes the user to their designated dashboard based on role.
4. Dashboards query/mutate data (SPKs, inventory, etc.) using Supabase Client directly or via `services/`.
